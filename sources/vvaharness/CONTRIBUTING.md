# Contributing

Thank you for your interest in `vvaharness`. We welcome issue submissions including bug reports, documentation, feature requests, and installation/setup problems subject to the Contribution Submission Terms below.

## Current status

VVAH is now open for community collaboration through GitHub Issues. The community can report bugs, request features, improve documentation, and ask setup questions through the issue forms in .github/ISSUE_TEMPLATE/

External Pull Requests are coming soon. They will be enabled through a fork and PR review model in a future release, with all PRs subject to required checks and review by Visa maintainers before merge. Watch the CHANGELOG and release notes for the announcement.

We are excited about where VVAH is heading and look forward to building it with the community. Your feedback and interest at this stage mean a great deal to the team.

## How you can help

Here are the ways to get involved today:

- **Report bugs.** If something isn't working as expected, let us know. Clear reproduction steps and environment details go a long way.
- **Share feedback.** If you have ideas for improving the tool — new features, workflow improvements, configuration options — we'd love to hear them.
- **Improve documentation.** If something in the docs is unclear or missing, flag it. Good documentation helps everyone.

## Getting in touch

Reach out to the maintainers at **`vvaharness@visa.com`**. We read everything and will follow up as bandwidth allows.

## Security issues

Please do **not** report security vulnerabilities through public channels. See [`SECURITY.md`](SECURITY.md) for the responsible disclosure process.
