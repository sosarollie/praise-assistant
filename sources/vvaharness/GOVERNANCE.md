# VVAH governance

## Roles
- Repository sponsor: accountable for public repository scope and resourcing.
- Lead Maintainer / Core Contributor: accountable for repository health and technical governance.
- Maintainers: accountable for reviewing and triaging public issues.
- Stage owner: accountable for their S0–S11 pipeline stage's code and delivery decisions.
- Security/privacy responders: accountable for sensitive-content and vulnerability escalation.

## Decisions
Changes to issue forms, security policy, workflows, and ownership require protected-branch review by the maintainers listed above.

## Transparency
Public issues should receive clear, respectful outcomes. Internal decisions, confidential data, security details, and personal information must not be disclosed publicly.
