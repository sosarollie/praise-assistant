# Support

## Use GitHub Issues for
- Reproducible defects (bugs) in this repository
- Feature requests and enhancements
- Documentation corrections
- Installation and setup problems

## What does not belong in Issues
- Security vulnerabilities
- Credentials or secrets
- Customer, payment, personal, or confidential information
- Requests requiring private support handling

For anything in this second list — security vulnerabilities in particular — use
the approved support or private security channel shown in the issue template
configuration.
