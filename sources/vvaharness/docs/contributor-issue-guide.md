# Reporting issues to VVAH

Use GitHub Issues to report bugs, documentation problems, and setup issues. Choose the form that best matches your request and select the VVAH step that is most relevant.

Before submitting, search existing issues and remove all credentials, tokens, personal data, customer information, payment data, internal system information, and security-sensitive material.

Use the private security reporting channel for vulnerabilities.
